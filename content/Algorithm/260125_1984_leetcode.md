문제링크[https://leetcode.com/problems/minimum-difference-between-highest-and-lowest-of-k-scores/]

## 나의 풀이
```java
class Solution {
    public int minimumDifference(int[] nums, int k) {
        int[] copy = nums;
        Arrays.sort(copy);
        int answer = Integer.MAX_VALUE;

        for(int i = 0; i + k - 1 < copy.length; i++) {
            int diff = copy[copy.length - 1 - i] - copy[copy.length - k - i];
            if(diff < answer) {
                answer = diff;
            }
        }
    

        return answer;
    }
}
```

## Solution
```java
class Solution {

    public int minimumDifference(int[] nums, int k) {
        int n = nums.length;
        Arrays.sort(nums);
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i + k - 1 < n; ++i) {
            ans = Math.min(ans, nums[i + k - 1] - nums[i]);
        }
        return ans;
    }
}
```
