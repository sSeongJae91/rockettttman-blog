# 26년 1월 12일 TIL Algorithms

문제링크[https://leetcode.com/problems/minimum-time-visiting-all-points]

```java
class Solution {
    public int minTimeToVisitAllPoints(int[][] points) {
        int time = 0;

        for(int i=0; i < points.length; i++) {
            if(i > 0) {
                int xPosition = Math.abs(points[i][0] - points[i-1][0]);
                int yPosition = Math.abs(points[i][1] - points[i-1][1]);

                time += Math.min(xPosition, yPosition) + Math.abs(yPosition - xPosition);
            }
        }    

        return time;
    }
}
```
